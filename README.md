# student-management-system
The Student Management System is a menu-driven Python program used to manage student records efficiently. It stores student information using a list of dictionaries, where each student record contains details such as ID, Name, Age, Course, and Marks.
its features:
 Add new student records
 View all student records
 Search students by ID or name
 Update existing student information
 Delete student records
 Exit the application
 Simple command-line menu
 working:
 When the program starts, it displays a menu containing different operations. The user selects an option by entering the corresponding number. The program then performs the selected operation and returns to the main menu until the user chooses the Exit option.
